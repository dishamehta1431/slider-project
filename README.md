## 📌 About The Project

A simple **Image Slider** created using **HTML, CSS, JavaScript, and Bootstrap**.

## 🚀 Technologies Used

* HTML
* CSS
* JavaScript
* Bootstrap 5

## ✨ Features

* Multiple images in a slider
* Previous and Next buttons
* Images added dynamically using JavaScript
* Bootstrap Carousel
* Gradient background
* Simple and clean design

## 💻 Project Description

In this project, I created an image slider using the **Bootstrap Carousel**.

The images are stored in a JavaScript array and added dynamically using the `forEach()` method.

The first image is displayed using the `active` class, and Bootstrap provides the Previous and Next slider functionality.
